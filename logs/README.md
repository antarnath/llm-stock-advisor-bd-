# 📝 Logs

Runtime logs from training, scraping, and inference runs.

## Convention

- Logs are **gitignored** (regenerated by code, large, noisy)
- Manual logs that capture research notes are kept here
- Script-generated logs use the format: `{module_name}_{YYYYMMDD_HHMMSS}.log`

## Manual Research Logs

This folder may contain:

- **`experiments.md`** — manual log of experiments tried
- **`decisions.md`** — architectural decisions and rationale
- **`issues.md`** — bugs encountered and how they were resolved
- **`data_quality_notes.md`** — observations about data quality, gaps, etc.

## Generating New Logs

When you run a script with file logging:
```python
from src.utils.logger import get_logger
logger = get_logger("my_script", log_to_file=True)
logger.info("This goes to console AND logs/my_script_20260813_123456.log")
```
