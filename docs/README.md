## How to Use

1. **New to project?** Start with [`PROGRESS.md`](PROGRESS.md) for current state
2. **Planning next phase?** Read [`phases/README.md`](phases/README.md) for full timeline
3. **Implementing a phase?** Open the specific `phase_XX_*.md` file for objectives, code examples, and success criteria
4. **Deploying?** Check [`architecture/`](architecture/) for system design
